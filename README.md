# Food Demand Forecasting and Waste Reduction Using Machine Learning

## Project Overview

This project aims to predict food demand using historical meal-order data and Machine Learning techniques.

It helps food businesses estimate future demand, improve food preparation planning and reduce potential food wastage.

## Objective

- Predict food demand using historical data.
- Improve food preparation planning.
- Reduce unnecessary food production.
- Support better resource management.

## Technology Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithm

Random Forest Regression

## Dataset

- train.csv
- meal_info.csv
- fulfilment_center_info.csv

## Model Evaluation

The model is evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)

## Project Outcome

The model predicts food demand based on historical data and provides insights that can support better food demand planning.
